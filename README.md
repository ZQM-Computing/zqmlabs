## About

ZQM Labs is an open-source, MIT-licensed technology organization building infrastructure across the [ZQM-MESH network](https://zqmlabs.com). Our projects span:

- **Security** — `zqm-security`, `zqm-attestation-active`, `zqm-shield`, `zqm-sword`
- **AI/ML** — `zqm-comfy`, `zqm-ai-council`, `zqm-void`, `zqm-quantum-sim`
- **Data** — `zqm-data-engine`, `zqm-economic-data`, `zqm-analytics`
- **Infrastructure** — `zqm-mesh`, `zqm-docker`, `zqm-nixos`, `zqm-bridge`
- **Monitoring** — `zqm-monitor`, `zqm-watchtower`, `zqm-log-shield`
- **Public Portals** — `zqmlabs-portal`, `company.zqmlabs.com`, `volusia-site`
